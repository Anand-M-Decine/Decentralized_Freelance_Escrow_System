# Decentralized Freelance Escrow System – DApp

A Web3 DApp that allows clients and freelancers to handle payments using Ethereum smart contracts.  
The payment is locked in a smart contract and is only released when the client approves the completed work.

This project is a working prototype and also my first Web3 project.

---

## How It Works

1. The client deploys the escrow smart contract.  
2. The client deposits ETH into the contract.  
3. The freelancer sees the funded job and submits the work.  
4. The client reviews the work and approves it.  
5. The smart contract automatically transfers the ETH to the freelancer.

---

## Smart Contract

- Written in **Solidity**  
- Deployed on **Ethereum Sepolia Testnet**  
- Holds and releases ETH based on job state  

---
